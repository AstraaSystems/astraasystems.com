# Installation Guide

## Requirements
- Python 3.10+
- ib_insync
- psutil

## Steps
1. Clone repository into /home/keshanth/ARKA/ardhanarishvara
2. Install dependencies:
   pip install ib_insync psutil
3. Ensure IB Gateway is running on port 7497
4. Run autonomous system:
   python3 execution/autonomous_system.py
