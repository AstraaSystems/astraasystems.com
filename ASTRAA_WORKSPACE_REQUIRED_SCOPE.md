# Astraa Workspace Required Scope

Astraa does not require an Android/iOS mobile app for the current SaaS system.

Astraa does require a browser-based Workspace portal.

## Not Required

- Android app
- iOS app
- App Store deployment
- Google Play deployment

## Required SaaS Workspace Capabilities

- Secure customer login
- Customer account dashboard
- Payment flow
- Automatic tool unlock after approved payment
- Saved customer data
- Estimator online
- Finance tool online
- Operations tool online
- Complete subscription self-management
- Usage limits and plan enforcement
- Full multi-tool enterprise dashboard
- Tool access based on plan/subscription status
- Customer billing/account status visibility
- Upgrade/downgrade or plan-management path

## Product Direction

Astraa Workspace is the required customer-facing SaaS portal.

It should run in the browser and does not need to be a mobile app.

The mobile app lane is out of scope, but the web portal, Finance, Operations, subscription automation, payment unlock, and dashboard are required for the intended Astraa SaaS product.
