Open Home, Pricing, Portal, and Contact. Logo should be clear image-only with no ugly square background.

Manual check

2. Trial Registration

Register with test data. Confirm redirect to customer portal and account details load.

Manual check

3. Portal Estimate

Run one estimate. Confirm usage moves from 0/15 to 1/15 and second same-day attempt is blocked.

Manual check

4. Expense Tool

Add one test expense. Confirm success message appears and no visual layout breaks.

Manual check

5. Contact Flow

Open contact page. Confirm mailto or fallback contact message works.

Manual check

6. Pricing Page

Confirm Core Plans, Individual Tool Pricing, Workspace Add-ons, and Custom Packages are all visible.

Manual check

7. Payment Preload

Confirm Basic and Professional can request Moneris checkout ticket through backend /preload.
